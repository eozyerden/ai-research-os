# AI Research OS — Framework Repository (Codex Entry Point)

This repository defines a framework for AI-assisted academic research. It is
not itself a research project.

Begin with `START_HERE.md`. It identifies the governing documents and the
authority boundaries.

Two rules specific to working on this repository:

* `templates/project/` is a template. Never modify it while creating an
  individual project; project-specific content belongs in the created project.
* `NEW_PROJECT.md` and `MIGRATE_PROJECT.md` are procedures to execute when
  asked to create or migrate a project.
