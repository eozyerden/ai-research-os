# AI Usage Records

This directory records consequential AI involvement in the project, per
`PRINCIPLES.md` §14, so that auditability does not depend on chat
transcripts.

For each consequential use, record:

* which tool was used;
* for what purpose;
* which artifacts it used;
* which artifacts it produced;
* what verification occurred;
* whether researcher approval was required.

Routine technical work does not need an entry.
